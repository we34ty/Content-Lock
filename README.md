# Content-Lock
Content-Lock is a progression- and combat-focused Minecraft datapack inspired by Souls-like and Terraria-style pacing. It introduces new structures, items, mechanics, and progression gates that reshape exploration and survival into a slower, more deliberate experience.

This project is still in active development. If you find bugs or have improvement ideas, please report them.

## Features
- Progression locks that gate equipment and advancement.
- New structures and worldgen content.
- Custom items, materials, and mechanics that deepen combat and exploration.
- Additional systems such as stamina, player motion tweaks, and utility content integrated into the pack.

## Version
Built for Minecraft 1.21.4 and ported to 1.21.11. Use 1.21.11 for best compatibility.

## Download & Install
1. Download or clone this repository.
2. Place the main folder (Content-Lock) in BOTH of these locations:
	 - Your world’s datapacks folder:
		 `.../.minecraft/saves/<Your World>/datapacks/`
	 - Your resource packs folder:
		 `.../.minecraft/resourcepacks/`
3. Enable the datapack and resource pack in-game.

## World Generation
For structures and terrain features to generate correctly, create a new world with the datapack enabled. If using an existing world, you should regenerate or explore new, ungenerated chunks.

## Configuration
Use the in-game function for options and tweaks:
`/function #content_lock:options`
